I’m a software engineer with 5+ years of hands-on experience building web and mobile applications, backend systems, APIs and production infrastructure. My strongest area is modern web apps with React, Next.js and TypeScript, while working across the backend with Django, Django REST Framework, Node.js and NestJS.

I like taking products the whole way — requirements and system design through implementation, integration, deployment and maintenance — especially business applications where software has to solve a real operational problem.

I value software that is maintainable, reusable, practical, reliable and structured to scale. I’d rather reach for a simple, well-structured solution than an unnecessary one, and I think good engineering is as much about the trade-offs you choose as the code you write.
